# NFTLab Sim — 1-minute pitch script

**0:00-0:12**

Have you ever hesitated to actually use an NFT because you were afraid of making a costly mistake?

> 実際にNFTを使うのをためらったことはありませんか?高価な資産で失敗するのが怖いからです。

**0:12-0:27**

NFTLab Sim turns quiz learning into hands-on practice. You answer questions about real NFT pilots, like ticket resale and loyalty programs.

> NFTLab Simはクイズ学習を実践的な体験に変えます。チケット転売やロイヤルティプログラムなど、実際のNFT事例について質問に答えます。

**0:27-0:42**

Once you pass a quiz, you unlock a matching sandbox scenario. There, you actually mint, transfer, and redeem demo NFTs, exactly like the real-world use-case, with zero financial risk.

> クイズに合格すると、対応するサンドボックスシナリオが解放されます。そこで実際にデモNFTをミント、転送、償還し、現実のユースケースを金銭的リスクゼロで体験できます。

**0:42-0:52**

It's all built on Solana Devnet, using Anchor, Metaplex, and Wallet Adapter, so every single action feels authentic but completely risk-free for the user.

> すべてSolana Devnet上に構築されており、Anchor、Metaplex、Wallet Adapterを使用しているため、すべての操作が本物のように感じられながら、完全にリスクフリーです。

**0:52-1:00**

Finish every scenario and earn a truly shareable certificate NFT. Practice first, then use NFTs with real confidence.

> すべてのシナリオを完了すると、本当にシェアできる修了証明NFTがもらえます。まず練習し、本当の自信を持ってNFTを使いましょう。
